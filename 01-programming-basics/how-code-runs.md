# How code runs

Code starts as text written in a programming language. A toolchain checks and processes that text so the computer can carry out its instructions. Depending on the language, this may involve compiling it into machine code, translating it to an intermediate form, or having a runtime interpret or execute it.

When you start a program, the operating system creates a process for it. The process receives resources such as memory and may open files or communicate over a network. The processor executes instructions, while the operating system helps coordinate access to hardware and other programs.

For example, a small program might read a number, calculate a result, and print it. The language defines what those statements mean; its runtime and the operating system help make them happen on a real machine.

## A useful mental model

Think of code as a plan, language tools as translators and helpers, and the processor as the machine that carries out the resulting instructions. The exact route from source text to execution depends on the language and platform.
