# Programming languages

A programming language is a way for people to express instructions and data in a form that software tools can process. Languages provide rules for writing programs, along with words and symbols for common ideas such as values, decisions, repetition, and reusable functions.

Languages make different trade-offs. Python is often chosen for its readable syntax and broad use in automation and data work. JavaScript is widely used to make web pages interactive and can also run on servers. Java is common in large applications and Android development. These are examples, not strict boundaries: each language can be used in many areas.

Computers ultimately execute machine instructions, so source code is processed by tools such as compilers and runtimes. The details vary by language: some programs are compiled ahead of time, some are interpreted, and many use a combination.

## Choosing a language

For a first language, choose one that supports the project or course you care about. Concepts such as variables, conditions, loops, and functions transfer between languages, so learning one language makes the next easier.
