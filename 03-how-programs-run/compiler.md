# Compiler

A compiler translates a program from one representation to another. Often it translates source code into machine code or an intermediate form that can be run later. Compilation can catch certain errors before the program starts, though it cannot prove that the program's behavior is correct.

Some languages are commonly compiled ahead of time into an executable. Others compile to bytecode that a virtual machine runs. Modern runtimes may also compile frequently used parts of a program while it is running.

The distinction between a compiler and an interpreter is not always absolute. A language implementation can compile some parts and interpret others; the important question is what tools process the code and when.
