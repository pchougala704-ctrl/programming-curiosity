# HTTP

Hypertext Transfer Protocol (HTTP) is a protocol used for communication between clients and servers on the web. A browser is one kind of client; it sends a request, and a web server sends back a response.

An HTTP request includes a method such as `GET` or `POST`, a path, headers, and sometimes a body. A response includes a status code, headers, and often a body containing HTML, JSON, an image, or another kind of data.

HTTP is stateless in the sense that each request is handled as its own message; applications can use cookies or tokens to connect requests to a user session. Ordinary HTTP does not encrypt traffic, so websites generally use HTTPS for communication over untrusted networks.
