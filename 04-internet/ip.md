# IP addresses

An Internet Protocol (IP) address identifies a network interface so data can be routed to it. IPv4 addresses look like `192.0.2.1`; IPv6 addresses are longer and were created to provide a much larger address space.

When data travels across networks, it is divided into packets. IP addressing helps routers forward those packets toward their destination. IP itself does not guarantee that every packet arrives, arrives in order, or is private; other protocols and security mechanisms provide additional behavior.

Some addresses are public and routable on the internet; others are private and used inside local networks. Network address translation can allow devices with private addresses to share a public address.
