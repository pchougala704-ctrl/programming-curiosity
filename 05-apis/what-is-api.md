# What is an API?

An application programming interface (API) is a defined way for one piece of software to interact with another. It describes which operations are available, what information they need, and what results or errors they can return.

For example, a weather service might provide an API that accepts a city and returns a forecast. The application using that API does not need to know how the service stores or calculates its weather data; it needs to follow the documented interface.

APIs can be used between parts of one program, between software libraries, or across a network. A web API is one common kind: a client sends requests to a server, often using HTTP.
