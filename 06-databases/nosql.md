# NoSQL

NoSQL is a broad name for database systems that do not rely solely on the traditional relational-table model. The category includes document databases, key-value stores, graph databases, and wide-column databases.

A document database might store a person and their preferences together as a JSON-like document. A key-value store might map a session identifier directly to session data. These models can be convenient for particular access patterns or flexible data structures.

NoSQL does not mean "no structure" or "no rules." Each system has its own data model, query tools, consistency guarantees, and trade-offs. Some systems also support transactions and structured schemas.
