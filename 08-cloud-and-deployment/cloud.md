# Cloud computing

Cloud computing provides computing resources over a network, usually through services that can be provisioned when needed. Instead of buying and operating every machine yourself, you can rent virtual machines, storage, databases, or higher-level application services.

Cloud services can make it easier to scale resources and deploy software in different locations. They do not remove the need to design, secure, monitor, and pay for those resources. A cloud provider operates some layers of the system, while the customer remains responsible for others.

The right service depends on a project's needs, budget, reliability goals, and operational skills. Cloud is one way to run software, not a requirement for every application.
