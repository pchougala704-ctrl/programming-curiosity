# Servers

A server is a computer or program that provides a service to other programs, called clients. A web server, for example, receives requests and sends back web pages or API responses.

The word "server" can refer to the software role or the machine running it. One physical computer can run many server programs, and one service can use many machines. A server process must be configured to listen for requests and to access whatever data or resources it needs.

Servers can run in a company's own facilities or on cloud infrastructure. In either case, they need maintenance, monitoring, updates, and appropriate security controls.
