# Java

Java is a general-purpose, statically typed programming language. A compiler commonly translates Java source code into bytecode, which runs on a Java Virtual Machine (JVM). The JVM allows the same compiled program to run on many systems that provide a compatible runtime.

Java is used in enterprise software, backend services, Android development, and other areas. Its type system and extensive libraries support large projects, though the syntax may feel more formal than some languages.

Java is not JavaScript. They are separate languages with different histories, designs, and runtime environments.
