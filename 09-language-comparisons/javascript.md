# JavaScript

JavaScript is the main programming language built into web browsers. It lets web pages respond to actions, update content, and communicate with web services. JavaScript can also run outside the browser, for example on servers using environments such as Node.js.

JavaScript is dynamically typed and has an event loop and asynchronous features that help programs handle tasks such as network requests. The language also includes details and historical behavior that are worth learning gradually.

JavaScript is distinct from Java despite the similar names. TypeScript is a popular language that adds a type system and is usually transformed into JavaScript to run in browsers or JavaScript environments.
