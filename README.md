# Programming Curiosity

Programming Curiosity is a beginner-friendly guide to the ideas behind the software we use every day. The goal is not just to memorize terms, but to understand why things work, how they fit together, and what questions to ask next.

## Learning path

You can read the sections in order, or jump to a topic you are curious about.

1. [Programming basics](./01-programming-basics/)
2. [Variables and memory](./02-variables-and-memory/)
3. [How programs run](./03-how-programs-run/)
4. [The internet](./04-internet/)
5. [APIs](./05-apis/)
6. [Databases](./06-databases/)
7. [Security](./07-security/)
8. [Cloud and deployment](./08-cloud-and-deployment/)
9. [Language comparisons](./09-language-comparisons/)
10. [Rabbit holes](./10-rabbit-holes/)

## How to use this guide

Start with the question that interests you. Follow the links between topics when a new term appears, and try the small examples in a programming language you know. The explanations are starting points: real systems have more detail, and that is part of the fun of exploring them.

Want to explore through questions instead? Use the [Programming Curiosity Challenge](./CHALLENGE.md), organized to match the folders below.
